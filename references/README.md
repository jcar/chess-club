# references/

Personal reference books used to plan the curriculum. **Everything in this
folder except this README is gitignored** (see `.gitignore`) and must stay that
way.

| Book | Used for |
|---|---|
| *Chess for Children* (Chandler & Milligan) | Topic order and "quiz after each topic" format for Steps 1–6 (K–5) |
| *How to Win at Chess* (Rozman) | Framing for grades 3–8: Center/Develop/Castle, CCA habit, draw rules, Steps 3–8 |
| *How to Reassess Your Chess* (Silman) | Advanced track (Steps 8–9): endgames, imbalances, pawn structure |
| *Fundamental Chess Openings* | Opening move orders only (Step 7+) |

Why: chess *facts* (moves, positions, rules) are not copyrightable and can be
reused. The *prose*, diagrams and exercise selections of a book are. These books
are read to decide what to teach and in what order; every explanation, script
and exercise in this app is written from scratch, and puzzles come from the CC0
Lichess puzzle database.

Do not commit files here, and do not paste passages from them into content.
